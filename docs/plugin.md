# Video Storyboard

Turn a video into a storyboard image plus a timestamped text index, so the model can quote a moment by cell.

- `video_storyboard`: build the sheet and transcript index
- `video_probe` / `video_zoom` / `video_locate`: inspect more detail on demand
- `video_storyboard_settings`: ASR, cache, browser port, and other settings

See the repository README for full usage and cost details.
