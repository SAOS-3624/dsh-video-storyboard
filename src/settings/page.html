依赖与下载

插件不静默安装系统软件；点“重新检查”看现状，命令可复制到终端执行。

ffmpeg / ffprobe

  • Windows：winget install Gyan.FFmpeg，或从 ffmpeg.org 下载后把 bin 加进 PATH。
  • macOS：brew install ffmpeg；Linux：用发行版包管理器。

yt-dlp（B 站/YouTube 链接才需要）

  • python -m pip install -U yt-dlp；装完在终端运行 yt-dlp --version 确认。
  • 也可以从 GitHub Releases 下载独立 exe。

本地 ASR / SenseVoice

  • 在 DSH 的语音设置里下载并选中本地语音提供方；本插件检测到宿主 speechToText 会优先用本地模型。
  • 没有本地模型时，填一个 OpenAI 兼容端点 + key 即可；只转写台词，不下载整片。

API Key

  • 云端示例：SiliconFlow API Key。本机端点（127.0.0.1/localhost）按设计不需要 key。
  • 环境变量优先于本页；如果 DSH_ASR_KEY 已设置，本页的 key 不会覆盖它。
