依赖与下载

缺少的依赖会出现官方下载按钮；插件只打开官方来源，不静默安装、不执行下载的文件。装好后回到本页点“重新检查”。

没有台词 ≠ 画面有问题

“本地 ASR”那一行只是宿主内置语音的状态。没配也能出图，只是清单里没有台词。 想要台词有两条免费路线（不联网、约 15 分钟）：sherpa-onnx（体积小、冷启动快） 或 FunASR；也可以给 B 站 cookie 直接读站点 CC 字幕，不用装 ASR。 两种都写在 docs/INSTALL.zh.md 第 3 步。

ffmpeg / ffprobe

  • Windows：下载官方 FFmpeg zip，解压后把里面的 bin 目录加进 PATH；或用 winget install Gyan.FFmpeg。
  • macOS：brew install ffmpeg；Linux：用发行版包管理器。
  • 装完用 ffmpeg -version 和 ffprobe -version 确认；本页只检查，不替你执行安装包。

yt-dlp（B 站/YouTube 链接才需要）

  • Windows 可直接下载 yt-dlp.exe，放到 PATH 里的目录。
  • 或用 python -m pip install -U yt-dlp；装完运行 yt-dlp --version 确认。

Python（可选）

  • 只有用 pip 安装 yt-dlp 或跑 Python 工具时才需要：下载 Python，安装时勾选 “Add python.exe to PATH”。

本地 ASR / SenseVoice

  • 优先在 DSH 的语音设置里下载并选中本地语音提供方；本插件检测到宿主 speechToText 会优先用本地模型。模型页面。
  • 直接下模型文件不会自动接上宿主，仍需在 DSH 语音设置里选提供方；本页只做检测。
  • 没有本地模型时，填一个 OpenAI 兼容端点 + key 即可；只转写台词，不下载整片。

API Key

  • 云端示例：获取 SiliconFlow API Key。本机端点（127.0.0.1/localhost）按设计不需要 key。
  • 环境变量优先于本页；如果 DSH_ASR_KEY 已设置，本页的 key 不会覆盖它。
